# Issue log

One entry per problem found. Severity: `fatal` (breaks Theorem 5.1), `major` (breaks a supporting statement or leaves a step unjustified), `minor` (fixable, does not affect the conclusion), `unclear` (we cannot tell what is being claimed). Every entry names the ledger row it affects.

## Index

| ID | Severity | Ledger row | Page / line | Summary | Status |
|---|---|---|---|---|---|

## Entry template

Copy this block for each new issue; IDs are `ISSUE-001`, `ISSUE-002`, ...

```
## ISSUE-NNN: <short title>

- **Severity:** fatal | major | minor | unclear
- **Where:** <ledger ID>, page <p>, paper.txt line <l>
- **What the paper says:** <quote>
- **What is wrong or missing:** <statement>
- **Why it matters for Theorem 5.1:** <statement>
- **Evidence:** <experiment, counterexample or reference>
- **Status:** open | confirmed | withdrawn
```
