described as U-standard according to the following rules: a set, monoid, topological
space, poset, family, graph, diagram, cardinal, ordinal etc. is standard when it is
small; a category, groupoid, multicategory, locally ordered category etc. is standard
when it is light; for 2 ≤ n < ∞, an n-category is standard when it is n-moderate.
A mathematical entity is described as U ∗ -standard according to the following rules:
an ∞-groupoid is standard when it is small; an (∞, 1)-category is standard when
it is light; for 2 ≤ n < ∞, an (∞, n)-category is standard when it is n-moderate. A
function, relation, subset, functor, natural transformation etc. is always standard.
